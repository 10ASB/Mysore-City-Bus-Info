# Mysore City Bus Information System (MCBI)

A responsive frontend starter for a student project concept focused on helping residents, students, visitors, and daily commuters explore public transportation information in Mysuru.

> **Status:** Frontend prototype. This repository does not currently include verified bus routes, official timetables, fare data, a backend, or live tracking. The route form demonstrates the UI only.

## Features
- Responsive landing page for desktop and mobile
- Route search form with location suggestions
- Demo journey response and input validation
- Sections for route discovery, bus stops, timings, and fares
- No build tools or package installation required

## Run locally
1. Download or clone this repository.
2. Open `index.html` in a modern browser.
3. Optional: use the VS Code Live Server extension.
