ABOUT THE PROJECT

Built around Mysuru's daily journeys.

Mysore City Bus Information System (MCBI) is a student project concept focused on making public transport information easier to discover for residents, students, visitors and daily commuters. This starter version demonstrates the interface; it does not connect to official live bus data.
